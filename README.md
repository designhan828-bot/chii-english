# 吉伊英语

适合小学阶段的英语学习 PWA。奶油色、粉色和薄荷绿界面，搭配吉伊学习伙伴，支持手机和电脑浏览器。

## 已实现

- 每天 20 个新词，分为 4 关；不足 20 个时按剩余数量安排。
- 翻卡释义、原创例句、英语朗读、跟读识别和手动练习记录。
- 连续 3 次语音识别正确后标记掌握；未掌握的已练词次日继续复习。
- 完成新词、复习和一道句子题后打卡，记录连续天数。
- 词库搜索、课程筛选、课程内单元筛选、学习状态筛选。
- 26 道原创语法题、3 个原创配音动画故事，支持 0.8× / 1× 和连续播放。
- 自动保存到本机浏览器、备份导出与恢复、PWA 安装、离线词卡和游戏。

## 教材内容

当前词库 **785 条**：冀教五上 80 条、新概念英语青少版 1A 363 条、1B 342 条。其中不同英文词目共 740 个，其余为不同教材中的重复词目或用法，不把词条总数称为去重词汇量。

冀教版为三年级起点、五年级上册、Unit 1 **School clubs** 版本；现有照片可核对 80 条，整册完整性尚未确认。新概念采用经典青少版 1A/1B，覆盖 30 单元，依据公开词表转录整理简明释义，仍需对照原书逐页核验，不声称官方完整词表。每个数据文件均记录来源与核验状态。

词库按冀教五上、青少版 1A、青少版 1B 的顺序安排，每日 20 个新词条。词库页可按课程、单元和状态筛选。新增词库保留稳定 ID，在 `src/catalog.ts` 注册；`src/content.ts` 中的例句、游戏与动画字幕为原创练习，不是课文复刻。

## 本地运行

需要 Node.js 24 和 pnpm 11.19.0。

```sh
pnpm install
pnpm dev
```

在浏览器打开终端输出的网址（通常为 http://127.0.0.1:5173/）。**不能直接双击源码 `index.html` 运行**。

```sh
pnpm test
pnpm build
pnpm preview
```

构建产物在 `dist/`。Vite 使用相对路径，适用于 GitHub Pages 仓库子路径。

## GitHub Pages

代码推送到 `main` 后，`.github/workflows/deploy.yml` 自动测试、构建和部署。在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。站点使用 HTTPS，手机可添加到主屏幕。

## 使用边界

- 进度仅保存在当前设备与浏览器，不会跨设备自动同步；换设备前请导出备份。
- 跟读依赖浏览器 SpeechRecognition；识别通常需要联网，可能不支持部分浏览器。应用不保存录音，但浏览器的语音服务可能处理音频。
- 识别匹配是练习辅助，不是专业发音评分。手动练习会完成今日任务，但不会增加语音连续答对次数。
- 发音依赖设备英语语音包；没有语音包时仍可阅读与手动练习。
- 角色素材用于本项目的个人学习原型，未声称获得官方授权。代码与角色素材不捆绑授予任何第三方角色版权。

## 结构

`src/catalog.ts` 管理课程注册、教材来源与排序；`src/domain.ts` 管理每日计划、复习、掌握、打卡和备份校验；`src/useSpeech.ts` 管理朗读和跟读生命周期；`src/App.tsx` 实现页面；`src/styles.css` 为独立儿童风格组件样式。`scripts/build-sw.mjs` 为每次构建生成版本化离线缓存。

测试涵盖每日 20 词、跨日复习、重复回调、连续答对、手动练习、打卡门槛、日期与备份校验、语音规范化及短语匹配。
